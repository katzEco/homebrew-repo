## Details

### [`katzu-git`](Formula/katzu-git.rb)
- **Type**: Formula (CLI)
- **Description**: A minimal, ergonomic CLI wrapper for everyday Git workflows. Installs the `kg` binary.
- **Repository**: [katzEco/katzu-git](https://github.com/katzEco/katzu-git)
- **Installation**:
  ```bash
  brew install katzu-git
  ```
